# V0.0.10 Battle Core Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans task-by-task. The user has authorized execution of the attached V1.2 order without repeated approvals.

**Goal:** Deliver a verifiable Android prototype implementing V1.2 P0/P1, with honest build gates and persistent round state.

**Architecture:** Keep the existing battle movement, targeting and drawing. Add a small `BattleCampaign` model owning squads, general HP and soldier proxy HP; the UI only selects squads and positions these same records for each round. End-of-round processing is idempotent and restores only eligible resting generals.

**Tech Stack:** Godot 4.4.1 / GDScript, headless SceneTree tests, Bash, existing Android debug CI.

**Spec:** `docs/specs/handoff-v1.2.txt` (the supplied, approved order).

## Global Constraints

- Independent branch `feature/battle-prototype-v0.0.10` from `74501530a8ef6fb15ba2f943f22e5e5b599e1a58`; do not touch the original HTML or merge to main.
- Each squad has 1–3 generals; attacker has 1–5 squads; defender has 1–10 squads.
- Exactly one squad per side fights at once. All generals at zero defeats a squad; all squads defeated ends the campaign.
- At 99 seconds, surviving sides withdraw without comparison; preserve exact HP and troop state.
- A squad resting for one completed encounter heals living generals by 10, capped by their own maximum; never revive zero HP.
- Might/intellect <=255, maximum HP/MP <=999, loyalty <=100. Prototype HP, damage, roster and item amounts stay explicitly provisional.
- P2 formal items, growth formulas, strategist skills and permanent save data are separate follow-ups. P3 requires user battle acceptance and the actual sealed HTML.

## Review Focus

- Re-entering selection or double-clicking finish must not grant extra rest healing or clone troops.
- A general killed earlier in a frame, or a dead soldier in the cached living list, must never attack later that frame.
- Repeated withdrawals with fractional proxy HP must not regenerate troops through rounding or reallocation.
- Back/home navigation must preserve the running encounter; only an explicit confirmed new campaign discards it.
- Ten defender squads, three long general labels and narrow phone widths must stay scrollable and reachable.
