# 三國工部 V0.0.11 P2 首批施工紀錄

《三國：我的三國我做主》第一代豪華重製版；依總部 V1.2 第6～10節施工。
基線為已交付的 `0c166db1187a7474dfb2dd2b23c7092307953654`，分支 `feature/battle-prototype-v0.0.11`。使用者提供的 V0.0.10 手機截圖顯示單場勝利、戰役勝利及中文，並批准繼續；不把舊版截圖當作新版實機驗收。

## 本批實裝

- 軍師技六項效果：恢復體力初／中／高每完整秒1／2／3HP，最多99次；增加體力進場一次50／100／200HP。封頂自身最大生命，陣亡者不復活，暫停／結束後不跳動，讀檔不重複進場治療。
- 武將／道具／军師技測試畫面：可選我軍任一隊伍及武將使用七類道具；可逐位指定我／敵軍測試技能對象。交戰含暫停期間禁止道具和技能配置。
- 武力丹、智力丹、生命仙丹、技力仙丹、生命靈藥、技力靈藥、珠寶；屬性上限255、最大HP／MP上限999、忠誠上限100；恢復遵守自己的最大值。增加上限不補當前值，無效不扣庫存。
- 道具數值為隔離的原型參數：屬性+5、上限／靈藥+30、珠寶+10，各初始2件；畫面明示，不是正式平衡或取得方式。
- 本機單一戰役存檔：包含庫存、配置、能力、精確HP／士兵傷勢和權重、場次、時間、位置、攻擊冷卻及本場效果。重新開啟停在首頁，按繼續才交戰。
- 建立、道具／配置改動、開場／結算、返回首頁／背景／明確退出時保存；交戰每5秒保存。暫存檔驗證後更名替換，保留上一份有效備份，主檔損毀可恢復備份。
- 無效資料及不相容版本拒絕載入，不部分套用、不擅自覆寫；重新建立需確認。存取失敗在畫面顯示，退出保存失敗會留在程式。
- 等級1／經驗0保留資料欄位，未添加未核定成長公式。APK版本0.0.11／code11；沿用既有中文系統字型與戰鬥原型。

## 範圍裁定

1. 在任務專用的乾淨工作目錄建立獨立分支，沒有第二名編輯者；若需同時編輯其他版本，須另開工作目錄。已驗收的0.0.10分支保留。
2. 技能對象使用明示的測試選擇器；正式作用範圍、耗費與配備限制未核定。總部核定後須調整配置介面，不把這次測試配置當成正式规则。
3. 所有本批治療不復活HP0武將，維持P1失能條件；若總部批准復活，須另外實作明確的復活效果。

## 限制與新版實機驗收

- 本批不是完整P2完工；正式成長公式、技能作用範圍／耗費／配備及美術仍待核定。沒有進行P3原版HTML搬遷或合併main。
- 強制終止可能回到最近成功保存點，通常為最近5秒檢查點；無法保證作業系統強殺前一定收到背景通知。只有本機存檔，沒有雲端同步。
- 沿用原型美術和既有圖示缺失提示，不能以桌面字型／測試推論Android觸控、字型回退及效能已通過。
- 安裝新版後請核對V0.0.11及中文；選副將使用仙丹，確認只加最大值；指定軍師技後進場，再暫停、退出、重新開啟，核對生命、兵力、時間、道具庫存且不重複進場治療。檢查捲到底部可操作返回鍵。
- V0.0.10沒有永久存檔，因此首次安裝V0.0.11不會自動帶回舊版已關閉的記憶體戰役。
