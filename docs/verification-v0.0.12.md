# 三國工部 V0.0.12：開局整備與戰場模型

工程為《三國：我的三國我做主》第一代豪華重製版，Godot 4.4.1。
基線 `39b991a097696234ccfeaaea47c04a6772ef762f`；獨立分支 `feature/battle-prototype-v0.0.12`。

本批依使用者「開局沒有軍師技入口，須先進戰役返回首頁；先做好群英傳3式戰場模型，再搬第一代內容」及繼續施工指令執行。

## 改動

- 首次啟動顯示「建立戰役並配置軍師技」；建立測試名冊後直接整備，尚未開始第一場戰鬥。
- 選隊頁增加「戰前整備 · 軍師技／道具」，直接開啟目前選中的我軍隊伍。返回按鈕及Android返回鍵均回到選隊，保留我／敵軍選擇並更新技能摘要。
- 保持進場才發動技能、交戰含暫停期間不能改配置、存檔不重複治療、無效存檔須確認才重建。
- 自繪原創戰場：遠山、旌旗、草地、道路；刀盾／長槍／弓箭兵的盔甲與兵器；騎乘武將、披風、步行／揮擊動作、弓兵射擊提示。依縱向位置排序遮擋，武將主副標示與血條另置上層。
- 初始兵陣改為6列、縱向13／橫向最多22邏輯單位間距（單兵種大隊依數量收窄），武將分別位於三條兵陣後方。位置會影響接敵路徑，但未修改傷害、克制、兵力代理、99秒或休整數值。讀取舊場次沿用已保存的位置。
- 繪圖獨立為 `scripts/battle_art.gd`，不寫回武將／士兵資料、不消耗亂數。沿用存檔版本與Android套件ID；APK版本0.0.12／code12。

## 驗收範圍

這是戰場原型的首批視覺改善，並非完整美術或P2/P3完工。武將技學習、軍師技正式解鎖／費用／作用範圍、成長公式仍依總部後續核定。本批未搬58城、內政等第一代封版資料，也未合併main。

一次獨立唯讀複核發現單一兵種超過66個士兵代理時，新兵陣可能超出場地，導致立即保存失敗。已以雙方各100個同兵種代理重現兩項失敗，改為依人數收窄間距後通過；其餘未發現本批阻塞項。複核未評定正式平衡、技能成長、美術觀感或Android效能。

Android實機請檢查：首次整備入口；選隊後配置並返回；兵種／騎將是否清楚；交戰流暢度；退出重開後HP、兵力及技能維持。桌面截圖及建置成功不能替代Android驗收。
